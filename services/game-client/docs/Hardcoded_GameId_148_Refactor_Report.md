### Refactor Report: Replace hard-coded `gameId = 148` with `GameIds.SeDie`

This document tracks the refactor that replaced literal `148` usages in the runtime workflow with the constant `GameIds.SeDie`, and lists remaining intentional hard-coded references.

---

### Summary

-   Replaced literal `148` in runtime control-flow with `GameIds.SeDie`.
-   Left style selectors and configuration keys as-is where they are data-driven or cosmetic.
-   Tests and docs still reference `148` explicitly for clarity and stability.

---

### Changes made (runtime code)

-   `src/_shared/react-contexts/url-context.ts`

    -   Default `gameId` now uses `GameIds.SeDie` instead of `148`.

-   `src/components/page-components/splash-screen/index.tsx`

    -   Default/fallback game and validation bypass now compare with `GameIds.SeDie`.
    -   Log messages updated to reference SeDie instead of numeric literal.

-   `src/components/game-base/index.tsx`

    -   `betPayloadFormat` selection uses `this.props.id === GameIds.SeDie`.

-   `src/components/game-base/handlers/pf-wrapper/pf-wrapper.tsx`

    -   Force attach `clientSeed` on bet events when `props.gameId === GameIds.SeDie`.

-   `src/games/sedie-multiplayer/scoreboard-elements.tsx`
    -   Scoreboard registration uses `GameIds.SeDie`.

---

### Remaining hard-coded references (intentional)

-   `src/styles/main.scss`

    -   `.game-148` layout rules. Cosmetic; tied to DOM class generated by `gameId`.
    -   Optional improvement: add a semantic class (e.g., `.game-sedie`) or data-attribute `data-game="sedie"` and mirror rules for clarity.

-   `game-settings.json`

    -   Keyed by numeric IDs (e.g., `"148": { ... }`). This is data/config and should remain numeric for compatibility.

-   Tests

    -   `src/_shared/react-contexts/__tests__/url-context.test.ts`
    -   `src/__tests__/url-context/url-parameter-combinations.test.ts`
    -   `src/components/page-components/dashboard/**/__tests__/**`
    -   Purposefully keep literals to validate behavior against canonical ID values.

-   Documentation
    -   Existing docs (including this one) refer to `gameId=148` for readability and audit trail.
