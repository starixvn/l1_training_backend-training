# Soccer PinGoal - 彈珠台軌道競賽遊戲需求文件

## 🎮 遊戲概述

Soccer PinGoal 是一款基於彈珠台機制的多人競賽遊戲。玩家選擇軌道和對手數量，珠子在軌道中下落並撞擊得分物件，最高分獲勝。

## 🏗️ 核心遊戲機制

### 軌道系統
- **軌道數量**: 6條軌道 (Tunnel 1-6)
- **軌道特性**: 每條軌道只能放置一顆珠子
- **軌道設計**: 從上到下的垂直軌道，包含各種碰撞物件

### 玩家選擇系統
1. **軌道選擇**: 玩家從1-6中選擇一條軌道放置自己的珠子
2. **對手數量**: 玩家選擇1-5個對手珠子
3. **對手軌道分配**: 系統隨機將對手珠子分配到剩餘軌道

### 計分機制
- **得分物件**: 軌道中設置不同的碰撞物件
- **分數設定**: 
  - 低分物件: 1分
  - 中分物件: 2分  
  - 高分物件: 3分
- **分數累積**: 珠子下落過程中撞擊物件，累積總分

### 勝負判定
- **獲勝條件**: 
  - 玩家珠子分數最高 → 獲勝
  - 玩家珠子與其他珠子並列最高分 → 獲勝
- **失敗條件**: 玩家珠子分數低於最高分

## 💰 賠率系統

賠率根據對手數量動態調整：

| 對手數量 | 獲勝概率 | ODDS倍數 | 難度等級 |
|---------|---------|----------|----------|
| 1個對手 | 50%     | 1.8x     | 簡單     |
| 2個對手 | 33.3%   | 2.5x     | 普通     |
| 3個對手 | 25%     | 3.2x     | 中等     |
| 4個對手 | 20%     | 4.0x     | 困難     |
| 5個對手 | 16.7%   | 5.5x     | 極難     |

## 🎯 遊戲流程設計

### 投注階段 (25秒)
1. **軌道選擇**: 玩家點選軌道1-6
2. **對手數量選擇**: 玩家選擇1-5個對手
3. **投注金額**: 確認投注金額
4. **ODDS顯示**: 實時顯示當前賠率
5. **投注確認**: 確認所有選擇

### 遊戲進行階段 (3秒)
1. **軌道分配**: 系統隨機分配對手珠子到剩餘軌道
2. **準備動畫**: 顯示所有珠子在起始位置
3. **倒數計時**: 3-2-1倒數

### 結果階段 (5秒)
1. **珠子掉落**: 所有珠子同時開始掉落
2. **碰撞動畫**: 顯示珠子撞擊物件的動畫效果
3. **分數統計**: 實時顯示各珠子累積分數
4. **結果宣布**: 顯示最終排名和獲勝珠子

### 結算階段 (2秒)
1. **勝負判定**: 確定玩家是否獲勝
2. **獎金計算**: 根據ODDS計算獎金
3. **餘額更新**: 更新玩家餘額

- **反彈效果**: 真實的物理反彈

```typescript
interface GameRound {
  playerTunnel: number;        // 玩家選擇的軌道 (1-6)
```

## 📊 遊戲平衡設計

### 分數分佈算法
- **物件密度**: 每條軌道固定數量的得分物件
- **分值比例**: 1分:2分:3分 = 50%:30%:20%
- **位置分佈**: 避免某條軌道明顯優勢
- **隨機因子**: 每局重新隨機分佈物件

### 賠率計算
```
基礎賠率 = 1 + (對手數量 * 風險係數)
最終賠率 = 基礎賠率 * 平台抽水係數(0.95)
```

### 風險控制
- **投注限額**: 根據玩家等級設定上限
- **連續獲勝**: 實施反作弊機制
- **統計分析**: 監控異常投注模式

## 🎲 隨機數生成需求

### 需要隨機的元素
1. **對手軌道分配**: 從剩餘軌道中隨機選擇
2. **物件分佈**: 每條軌道的得分物件位置
3. **碰撞結果**: 珠子撞擊物件的結果
4. **物件分值**: 各位置物件的分值分配

### 隨機數使用
- **種子數量**: 需要6-8個隨機數
- **分配方式**:
  - 隨機數1-5: 對手軌道分配
  - 隨機數6: 物件分佈種子
  - 隨機數7-8: 碰撞結果影響因子
