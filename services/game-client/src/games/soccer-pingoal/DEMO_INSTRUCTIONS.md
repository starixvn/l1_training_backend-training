# Soccer PinGoal - Demo 版本說明

## 🎮 Demo 特色

### ✅ 已完成的功能
1. **文字結果顯示** - 取代影片播放器，直接顯示遊戲結果
2. **軌道選擇系統** - 支援 1-6 軌道選擇
3. **對手數量設定** - 支援 1-5 個對手選擇
4. **實時勝率顯示** - 根據對手數量顯示獲勝機率
5. **賠率計算** - 動態顯示對應賠率
6. **Provably Fair** - 完整支援公平驗證
7. **響應式設計** - 支援桌面和移動端

### 🎬 文字結果顯示內容
當遊戲結束時，會顯示包含以下信息的結果卡片：

#### 📊 遊戲配置
- **選擇軌道**: 顯示玩家選擇的軌道（軌道 1-6）
- **對手數量**: 顯示選擇的對手數量（1-5 個對手）

#### 🏆 遊戲結果
- **勝負狀態**: 🏆 獲勝! 或 ❌ 失敗!
- **結果說明**: 詳細的勝負描述文字
- **視覺效果**: 獲勝顯示綠色，失敗顯示紅色

#### 📈 統計信息
- **獲勝機率**: 根據對手數量顯示實際勝率
- **賠率**: 對應的賠率倍數
- **影片URL**: Demo版本會顯示對應的影片檔案路徑

## 🎯 Demo 流程

### 1. 遊戲開始階段
```
📱 玩家介面
├── 軌道選擇 (1-6)
├── 對手數量選擇 (1-5)  
├── 投注金額設定
└── 確認開始遊戲
```

### 2. 遊戲進行階段
```
🎲 滾動中...
├── 顯示 "珠子正在滾動中..." 提示
├── 藍色背景的準備畫面
└── 倒計時等待結果
```

### 3. 結果顯示階段
```
📋 結果卡片
├── 🎮 軌道彈珠遊戲 (標題)
├── 📊 遊戲配置 (軌道 + 對手數量)
├── 🏆 勝負結果 (獲勝/失敗 + 說明文字)
├── 📈 統計信息 (勝率 + 賠率)
└── 📹 影片URL (demo用)
```
